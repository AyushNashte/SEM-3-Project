# EduSnap 📚

EduSnap is an educational learning assistant designed to help
Class 7–10 students understand difficult concepts in a simple
and easy-to-understand way.

## 🎯 Project Objective

The main goal of EduSnap is to make learning easier by providing
simple explanations, worked examples, visual aids, and quizzes
for students.

The initial focus of the project is **Mathematics for Class 7–10**.

## 👨‍🎓 Target Users

- Class 7 students
- Class 8 students
- Class 9 students
- Class 10 students

## ✨ Planned Features

- 📖 Simple concept explanations
- 📝 Step-by-step worked examples
- 🖼️ Visual aids such as images and diagrams
- 🎯 Short quizzes
- 📚 Class 7–10 Mathematics topics
- 🌐 Chrome Extension interface

## 🧮 Initial Mathematics Topics

The project will initially focus on important topics such as:

- Fractions and Decimals
- Percentage
- Ratio and Proportion
- Algebra
- Linear Equations
- Factorisation
- Geometry
- Pythagoras Theorem
- Coordinate Geometry
- Statistics
- Probability
- Trigonometry
- Mensuration

The exact topics will be finalized during development.
